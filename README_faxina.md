# Faxina de dados



Limpa nomes, telefones e datas de um CSV.



## Arquivos

- `limpeza.py`: funções `limpar_nome`, `limpar_telefone` e `limpar_data`

- `faxina.py`: lê `sujo.csv`, aplica as funções e grava `limpo.csv`



## Como rodar

```

python faxina.py

```

O arquivo `limpo.csv` será criado na mesma pasta.
